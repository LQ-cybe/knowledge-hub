# 术语表

这里用大白话解释你在使用 Python 程序开发过程中可能遇到的各种术语。不需要全记住，遇到不懂的回来查就行。

## 基础概念

### Python
一种编程语言，通俗理解就是"让电脑按你的想法干活的语言"。就像你要告诉助手"帮我把这些文件整理好"，Python 就是用来写这种"指令"的工具。

### 程序 / 脚本
其实就是一份"给电脑的指令清单"。你打开一个程序 → 电脑按照清单一步步执行 → 最后得到你要的结果。

### exe
Windows 上可以直接双击运行的程序文件。就像你双击打开微信、浏览器一样，不需要安装任何额外的东西。别人收到一个 exe 文件，双击就能用。

### 源代码
程序的"原始写法"，一般是 `.py` 结尾的文件，需要电脑装了 Python 才能运行。适合开发者之间传递，不适合直接发给普通用户。

## 工具类

### uv
一个帮你管理 Python 环境的工具。它的作用是：
- 帮你装 Python（如果你的电脑上没有）
- 帮你装程序需要的各种"零件"（叫"依赖"或"包"）
- 帮你运行程序、测试程序

你不需要手动操作它，AI 会帮你执行所有 uv 命令。

### pip
Python 自带的"零件安装器"，和 uv 的职责类似。本项目统一用 uv 来代替 pip，效率更高。

### PyInstaller
一个"打包工具"，能把 Python 程序变成一个独立的 exe 文件。这样你就可以把程序发给任何人，他们不需要装 Python 也能双击运行。

### 终端 / 命令行
一个黑底白字的窗口，可以通过敲文字来控制电脑。对于零基础用户，**不推荐直接使用终端**。本文档默认所有终端操作由 AI 代劳。

## 项目结构类

### pyproject.toml
项目的"身份证和说明书"。里面记录了：
- 项目叫什么名字
- 需要哪些零件（依赖）
- 怎么启动它

这是一个固定的标准格式，你不用自己写，AI 会帮你生成。

### src
源代码放在 `src/` 目录里，这是项目结构的一部分。就像把文件放在"文档"文件夹一样，把代码放在 `src/` 里比较清晰。

### .env
配置文件，里面放一些可以修改的设置，比如"输出目录在哪"、"日志级别是什么"。好处是换个环境不用改代码，只改这个文件就行。

### .env.example
配置文件的模板。真正的 `.env` 文件一般不会放到网上（里面可能有密码），但 `.env.example` 是一个无害的模板，告诉你有哪些配置项可以改。

### .gitignore
告诉 git（版本管理工具）哪些文件不需要管。比如临时文件、缓存、打包产物都不需要记录版本。

## 运行和测试

### 日志 (log)
程序运行时的"工作记录"。如果程序出错了，看日志就能知道是在哪一步出的问题。日志文件通常放在 `logs/` 目录下。

### 测试 (test)
写一些"模拟场景"来验证程序是否正常。比如"如果输入正常文件，程序应该输出正确结果"、"如果输入空文件，程序应该给出友好提示"。测试能帮你在改代码后快速确认没有改坏。

### 依赖
程序要正常运行所需要的"零件"。比如你的程序要处理 Excel，就需要 `openpyxl` 这个零件。uv 会自动帮你把需要的零件都装好。

## 编码相关

### UTF-8
一种通用的文字编码方式，能正确显示中文、英文、表情等各种字符。如果你的程序输出中文乱码，多半是编码没设对。

### BOM
UTF-8 编码的"文件头标记"，告诉电脑"这个文件是 UTF-8 编码"。在 Windows 的 PowerShell 脚本中，加上 BOM 能有效避免中文乱码。

### CRLF / LF
换行符的两种格式。Windows 用 CRLF（回车+换行），Linux/Mac 用 LF。在 Windows 上写脚本时用 CRLF 最稳妥。

## 界面类

### tkinter
Python 自带的一个做窗口界面的工具库，不需要额外安装。做出来的窗口比较朴素，但胜在稳定、打包体积小。

### PySide6
另一个做窗口界面的工具库，界面更现代、更好看，但打包出来的文件会更大。适合对界面美观有要求的场景。

### GUI (Graphical User Interface)
"图形用户界面"，就是有窗口、有按钮、能看到内容、能用鼠标点的界面。和"命令行"（黑底白字敲指令）相对。

---

## 网络相关

### 镜像
一个"国内备份站"。因为很多 Python 零件存放在国外服务器，国内下载很慢，所以国内的大学和公司提供了镜像备份，下载速度飞快。

### API (Application Programming Interface)
"程序接口"，简单理解就是"别人写好的功能，你可以通过网址来调用"。比如用天气 API 可以获取天气预报，不用自己去气象局拿数据。

### 爬虫 / 抓取
"自动从网页上拿数据"。比如你每天手动打开一个网页、复制表格数据、粘贴到 Excel，这个过程可以写成程序自动完成。

### Playwright
一个控制浏览器的工具，可以让程序模拟人类操作网页——打开页面、点击按钮、填写表单。适合需要登录或点击才能看到内容的网站。

---

## 交付相关

### 打包 (build / package)
把源代码变成可以直接运行的形式。对零基础用户来说，最常见的就是"打包成 exe"。

### onefile
PyInstaller 的一种打包模式，把所有内容打包成**单个 exe 文件**。优点是只有一个文件，方便传递；缺点是启动稍慢。

### onedir
PyInstaller 的另一种打包模式，打包成一个**文件夹**，里面包含 exe 和各种支持文件。优点是启动快；缺点是文件多，传递时需要整个文件夹。

### LicenseId / WatermarkText
如果你要把程序发给别人用，可以在 exe 里嵌入"发给谁的标记"。这样如果程序被二次传播，可以追溯到最初的接收者。这是保护你劳动成果的一种方式。
