# 常见问题排障指南

面向零编程基础用户，遇到问题时先看这里。每个问题都用大白话解释原因和解决办法。

## 使用方法

- 先找到和你遇到的情况最像的描述
- 按"AI 会怎么帮你处理"里的步骤来
- 如果下面的方案都不管用，把完整的报错截图发给 AI

---

## 环境安装类

### Q1: 运行程序时提示"找不到 uv"或"uv 不是命令"

**这是什么意思**：程序运行需要的工具还没装好。

**AI 会怎么帮你处理**：AI 会重新帮你安装 uv，你只需要在弹出授权窗口时点"允许"。

### Q2: 安装包的时候一直卡住或下载失败

**这是什么意思**：国内访问国外下载源比较慢，容易超时。

**AI 会怎么帮你处理**：AI 会自动切换到国内镜像（清华、南大等），再重新下载。你不需要做任何操作。

### Q3: 提示"Python 版本不对"或"需要 Python 3.x"

**这是什么意思**：你电脑上的 Python 版本和程序要求不一致。

**AI 会怎么帮你处理**：AI 会帮你用 uv 安装正确版本的 Python，不会影响你电脑上已有的其他 Python。

---

## 运行类

### Q4: 双击 exe 一闪就没了

**这是什么意思**：程序运行过程中出错了，但窗口关闭太快看不到报错信息。

**AI 会怎么帮你处理**：
- 先检查日志文件（通常在程序所在目录的 `logs/` 文件夹里）
- 如果没有日志，AI 会在命令行里启动一次，让报错信息留下来
- 根据报错修复后重新打包

### Q5: 程序运行后没有生成结果文件

**这是什么意思**：程序可能执行完了但没找到输入文件，或者输出路径有问题。

**AI 会怎么帮你处理**：
- 检查程序的输入目录是否放了正确的文件
- 检查配置文件（`.env`）里的路径设置
- 查看日志确认具体是哪一步出了问题

### Q6: 运行时弹出红框报错

**这是什么意思**：程序在执行过程中遇到了无法自动处理的问题。

**AI 会怎么帮你处理**：把红框里的提示文字告诉 AI，或者截图发给 AI。通常这类问题都有具体的修复方案。

---

## 中文乱码类

### Q7: 程序输出的中文变成乱码或问号

**这是什么意思**：文件编码不对，这是 Windows 上最常见的问题之一。

**AI 会怎么帮你处理**：
- 如果是 `.ps1` 脚本文件：改用 UTF-8 with BOM 编码保存
- 如果是程序输出到文件：加上 `encoding="utf-8"` 参数
- 如果是 exe 里的中文：检查打包参数是否包含了编码配置

### Q8: Excel 导出的中文是乱码

**这是什么意思**：和上面类似，是编码问题，但 Excel 场景有专门的处理方式。

**AI 会怎么帮你处理**：
- CSV 文件：改用 `utf-8-sig` 编码（Excel 能正确识别）
- 直接用 openpyxl 写 xlsx 文件（不会有编码问题）

## 打包类

### Q9: 打包出来的 exe 文件特别大

**这是什么意思**：正常现象。Python 打包会将运行环境一起打包，几百 MB 都在合理范围内。

**AI 会怎么帮你处理**：如果确实需要减小体积，AI 可以尝试精简依赖、使用 `--onedir` 模式等。但不建议为了体积强行删依赖。

### Q10: exe 在别人电脑上打不开，提示"缺少 xxx.dll"

**这是什么意思**：打包时可能漏掉了一些系统依赖。

**AI 会怎么帮你处理**：
- 尝试用 `--onedir` 模式重新打包（包含更多依赖）
- 如果对方电脑是特别旧的系统，需要调整打包参数

### Q11: 打包后程序找不到 .env 文件或资源文件

**这是什么意思**：打包成 exe 后，文件路径发生了变化，程序按原来的路径找不到文件了。

**AI 会怎么帮你处理**：修改程序中读取文件的路径逻辑，让它从 exe 所在目录去找。

## 其他常见问题

### Q12: 安装环境时杀毒软件报毒

**这是什么意思**：某些打包工具生成的 exe 会被杀毒软件误报，属于正常现象（误报率高）。

**AI 会怎么帮你处理**：
- 开发/测试阶段：把项目目录加入杀毒软件白名单
- 发给别人用之前：用 VirusTotal 在线扫一下，确认是误报
- 长期方案：可以考虑数字签名认证

### Q13: 程序在 AI 的测试里正常，但我自己运行时不一样

**这是什么意思**：可能输入文件不同、电脑环境不同、或者配置文件不同。

**AI 会怎么帮你处理**：
- 把你实际运行时的输入文件、操作步骤、报错信息告诉 AI
- AI 会针对你的实际使用场景重新调试

---

## 还没解决？

把这些信息准备好，然后发给 AI：

1. **你做了什么操作**（点了什么按钮、选了哪个文件）
2. **期望的结果是什么**
3. **实际发生了什么**（报错截图最好）
4. **日志文件**（如果有的话，在程序目录的 `logs/` 文件夹里）

AI 会根据这些信息帮你定位问题。
