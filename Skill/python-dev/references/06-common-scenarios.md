# 常见场景库

这个文档用于处理高频 Python 需求时的快速判断。后续 AI 可先用它定位方向，再进入需求澄清、模板选择和交付流程。

## 使用方法

- 先看用户想解决的业务问题，而不是先看用户说了什么技术名词
- 先判断更适合脚本、桌面工具还是 `exe`
- 先选接近的蓝图，再补业务细节

## 场景一：批量文件处理

### 常见说法

- 帮我批量改文件名
- 帮我整理一个文件夹里的文件
- 帮我把一堆图片、PDF、Excel 自动处理掉

### 默认判断

- 自己用为主：优先脚本
- 要给同事或运营人员使用：优先桌面工具或 `exe`

### 必问问题

- 输入目录在哪里
- 是否递归子目录
- 输出是覆盖原文件还是另存
- 命名规则、筛选规则、异常文件怎么处理

### 推荐蓝图

- `templates/project-blueprints/cli-batch`

## 场景二：Excel / 表格批处理

### 常见说法

- 帮我批量处理 Excel
- 帮我把表格格式统一一下
- 帮我把多个表合并成一个

### 默认判断

- 规则固定、自己用：脚本或命令式批处理
- 需要普通用户选文件再处理：桌面工具或 `exe`

### 必问问题

- 输入文件格式是 `xlsx`、`csv` 还是混合
- 输出是新文件还是覆盖原文件
- 是否有样例文件和期望结果
- 是否需要保留原格式、公式、颜色、合并单元格

### 推荐蓝图

- `templates/project-blueprints/cli-batch`
- `templates/project-blueprints/gui-exe`

## 场景三：网页抓取

### 常见说法

- 帮我抓网站数据
- 帮我做个爬虫
- 帮我每天抓某个网页的数据

### 默认判断

- 只需自己定时或手动跑：脚本
- 需要普通用户点一下按钮就抓：桌面工具

### 必问问题

- 网站链接
- 是否需要登录
- 需要抓哪些字段
- 输出到哪里
- 访问频率要求

### 特别提醒

- 涉及登录、Cookie、账号密码时，要先确认授权和安全边界
- 不要默认所有抓取都适合 GUI

## 场景四：桌面小工具

### 常见说法

- 帮我做个桌面小工具
- 我想双击就能用
- 不想让别人碰终端

### 默认判断

- 优先 GUI
- 默认考虑 `exe`

### 必问问题

- 窗口里要有哪些输入项和按钮
- 是否要选择文件
- 是否要进度提示和完成提示
- 结果放在哪里

### 推荐蓝图

- `templates/project-blueprints/gui-exe`

## 场景五：接口调用 / 数据同步

### 常见说法

- 帮我调用某个接口
- 帮我同步系统数据
- 帮我自动推送信息

### 默认判断

- 如果最终用户不是开发者，不要默认暴露 API 概念和密钥配置细节
- 优先把配置收口到 `.env` 或配置文件

### 必问问题

- 接口文档或样例请求
- 认证方式
- 失败重试策略
- 输出格式和日志需求

## 蓝图选择速查

| 用户场景 | 优先蓝图 |
|----------|----------|
| 批量处理目录文件 | `cli-batch` |
| Excel 文件整理并给同事使用 | `gui-exe` |
| 自己定时抓网站数据 | `cli-batch` |
| 双击运行的小工具 | `gui-exe` |

## 最后原则

- 不要因为用户说了“Python”就默认交付源码
- 不要因为用户说了“自动化”就默认交付命令行
- 不要因为用户说了“exe”就跳过需求澄清
