# CLI 批处理蓝图

适用场景：

- 批量文件处理
- Excel / CSV 清洗
- 网页抓取后导出文件
- 定时执行或手动运行的自动化任务

蓝图目标：

- 使用 `src` 结构
- 保留清晰的核心处理入口
- 默认包含最小测试
- 适合继续打包为命令行工具或迁移到 GUI

建议搭配：

- `references/07-common-scenarios.md`
- `templates/bootstrap_project.ps1`
