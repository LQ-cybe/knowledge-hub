# 示例需求

以下是零基础用户可能提出的典型需求，帮助 AI 识别场景并路由到对应蓝图。

## 场景速查表

| 场景 | 典型需求 | 对应蓝图 |
|------|----------|----------|
| CLI 批处理 | 把一个文件夹里的文件按规则重命名并输出处理清单 | cli-batch |
| 桌面工具 | 做个能双击运行的桌面工具，帮同事处理数据 | gui-exe |
| Excel 批处理 | 把多个 Excel 按指定列合并，输出总表 | excel-batch |
| 网页抓取 | 输入网址后自动抓取内容并导出为 Excel | web-scraper |

---

## 对话示例

以下是零基础用户可能的提问方式和 AI 应该怎么回应。

### 示例一：文件批处理

**用户**：帮我整理一下电脑上这些照片，按拍摄日期分到不同文件夹里

**AI 思路**：
1. 命中"批量文件处理"场景 → 参考 `../references/06-common-scenarios.md` 场景一
2. 判断为"自己用、不太需要窗口" → 优先 CLI 脚本
3. 需要澄清：照片在哪、命名规则、是否保留原文件 → 参考 `../references/01-need-discovery.md`

**AI 回应**（需求澄清阶段）：
> 我理解了，你是想把一个文件夹里的照片按日期重新整理对吧？我先确认几个细节：
> 1. 照片现在放在哪个文件夹？
> 2. 日期信息是从文件属性里读，还是文件名里本身有日期？
> 3. 整理后原照片是保留还是移动？
> 4. 这个工具就你自己用吗？
>
> 按你的说法，我建议做成一个脚本，你每次运行它就会自动整理。不需要装任何软件。

---

### 示例二：Excel 合并（给同事用）

**用户**：我们部门每周有人填一个 Excel 模板，周五要手动合并成一张总表，好烦，能不能自动搞？

**AI 思路**：
1. 命中"Excel 批处理"场景 → 参考 `../references/06-common-scenarios.md` 场景二
2. 关键信息："给同事用" → 需要 GUI + exe，参考场景二的默认判断
3. 推荐蓝图：gui-exe 或 excel-batch

**AI 回应**（需求澄清阶段）：
> 这个完全可以自动化。我再问几个细节：
> 1. 大家的 Excel 模板格式一样吗？（表头一样、只是填的内容不同？）
> 2. 文件是怎么收集的——发到一个共享文件夹，还是你手动收？
> 3. 合并的时候是所有表的内容都拼到一起，还是需要按某些条件筛选？
> 4. 这个工具是你用还是部门其他人也要用？
>
> 如果需要别人也能用，我可以帮你做成一个带窗口的小工具，别人把文件放进去点按钮就合并好了。

---

### 示例三：网页数据抓取

**用户**：帮我每天自动去这个网站查一下最新报价，存到 Excel 里

**AI 思路**：
1. 命中"网页抓取"场景 → 参考 `../references/06-common-scenarios.md` 场景三
2. 判断为"自己定时跑" → 优先脚本
3. 需要澄清：网址、是否登录、抓哪些字段、输出格式
4. 特别提醒里的"授权和安全边界"

**AI 回应**（需求澄清阶段）：
> 好的，我先了解几个关键信息：
> 1. 能把网址发给我吗？
> 2. 查报价需要登录吗？如果需要，是公共账号还是你的个人账号？
> 3. 你需要抓哪些信息？比如"产品名称、今日价格、涨跌幅"这样？
> 4. 结果是每天追加到同一个 Excel，还是每天生成新的？
> 5. 你希望它完全自动每天跑一次，还是你手动点一下就查？
>
> 另外提醒一下，如果网站需要登录，我会帮你把账号信息存到安全的配置文件里，不会写死在代码里。

---

### 示例四：桌面小工具

**用户**：我想做个能双击打开的小软件，输入客户编号就能查到他的订单信息

**AI 思路**：
1. 命中"桌面小工具"场景 → 参考 `../references/06-common-scenarios.md` 场景四
2. 默认判断：优先 GUI，默认 exe
3. 推荐蓝图：gui-exe

**AI 回应**（需求澄清阶段）：
> 明白了，做一个小窗口，输入编号就查信息。我再确认几点：
> 1. 订单信息现在存在哪？是 Excel 表格、数据库、还是其他系统？
> 2. 你希望查出来显示哪些信息？（客户名、订单金额、下单日期？）
> 3. 这个工具是你自己用还是同事也要用？
> 4. 需要能"导出查询结果"或者"打印"吗？
>
> 我可以帮你做成一个带输入框和查询按钮的小窗口，双击就能打开，不需要装任何东西。查到的结果会清晰地显示在窗口里。

---

### 示例五：模糊需求（需要深度引导）

**用户**：帮我写个 Python

**AI 思路**：
1. 这是模糊需求，不能直接开工 → 参考 `../references/01-need-discovery.md` 中"不要急着开工的情况"
2. 用首轮建议话术引导

**AI 回应**（需求引导阶段）：
> 没问题！不过"写个 Python"范围太广了，我怕做出来不是你要的。你先别管技术，就按你现在的操作说说：
>
> 你现在是手工在做什么事情觉得费时间？比如"每天要复制粘贴很多数据到 Excel"、"要手动改几百个文件名"、"要打开网页翻好几页找信息"……随便描述一下就行。
>
> 这样我能帮你判断最适合做成什么样子。

## 蓝图选择决策树

```
用户需求
├── 只是自己用，不需要花里胡哨
│   ├── 处理文件/数据 → CLI 脚本（cli-batch）
│   ├── 抓网页数据 → Web 抓取脚本（web-scraper）
│   └── 处理 Excel → Excel 批处理（excel-batch）
│
├── 要给同事/别人用，或者需要窗口点击
│   ├── 主要处理 Excel → GUI + Excel 能力（gui-exe + excel-batch）
│   ├── 主要抓网页 → GUI + 抓取能力（gui-exe + web-scraper）
│   └── 其他 → GUI 桌面工具（gui-exe）
│
└── 要发给完全不懂技术的人
    └── 必须打包成 exe + 附带使用说明
```
