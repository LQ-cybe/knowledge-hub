# excel-batch 蓝图

适合批量读取和输出 Excel 的 .NET 工具。普通用户长期使用时，可进一步升级成 GUI。

- 默认从 `net6.0` 起步
- 如果确认 `.NET 6` 在依赖或 API 上不够，再升级到 `net8.0`
- 目标用户含部分 `Win10` 时，不要默认直接上 `net10.0`
