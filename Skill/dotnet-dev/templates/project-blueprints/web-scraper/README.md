# web-scraper 蓝图

适合静态网页抓取、接口轮询和简单内容采集。复杂浏览器自动化需求再单独扩展。

- 默认从 `net6.0` 起步
- 如果确认 `.NET 6` 不够，再升级到 `net8.0`
- 只有明确需要高版本 API 或包时，才考虑 `net10.0`
