title: SimplePanel
---

It is recommended to use this lightweight class instead Grid.

```cs
public class SimplePanel : Panel
```
{% note info %}
Most of the time, we try to avoid using heavyweight `Panel`, `SimplePanel` is used extensively in HC.
{% endnote %}
