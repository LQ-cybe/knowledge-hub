# CalendarBaseStyle

The default style of the calendar is not recommended for direct use and should always be used by other styles in the BasedOn mode.

{% note info no-icon %}
Example：

{% code lang:xml %}
<Calendar/>
{% endcode %}

{% note info %}
you can change calendar ui culture:

{% code lang:cs %}
ConfigHelper.Instance.SetLang("en");
{% endcode %}

{% endnote %}
