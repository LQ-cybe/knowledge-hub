# 示例需求

以下是零基础用户可能提出的典型需求，帮助 AI 识别场景并路由到对应蓝图。

| 场景 | 典型需求 | 对应蓝图 |
|------|----------|----------|
| CLI 批处理 | 把一个文件夹里的所有 PDF 文件按修改日期重命名，输出处理结果清单 | `cli-batch` |
| 桌面工具 | 做一个能双击运行的桌面工具，让同事选择 Excel 文件后自动生成汇总结果 | `gui-exe` |
| Excel 批处理 | 把多个 Excel 文件按指定列合并，输出一个总表，普通同事双击就能用 | `excel-batch` |
| 网页抓取 | 输入网址后自动抓取标题、发布时间和正文摘要，导出成 Excel | `web-scraper` |
