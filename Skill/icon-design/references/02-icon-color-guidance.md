# 图标配色轻量指引

这份指引用于补充 `icon-design` 的轻量配色能力。

目标不是替代完整的配色设计 skill，而是让 AI 在用户选图标时，顺手给出**更像设计建议**的颜色方向，并引导用户去 HTML 结果页里实际调整感受。

## 使用边界

- 适合：图标颜色建议、按钮图标颜色建议、功能入口图标配色、品牌 logo 的落地色建议
- 适合：用户给了参考图，希望 AI 从图里判断“更适合冷色还是暖色、低饱和还是高饱和”
- 适合：网页、后台、SaaS、控制台、品牌页、落地页、图表配套图标
- 不适合：完整品牌体系、整站 UI token 设计、复杂图表色板系统、专业视觉规范书

## AI 的工作方式

当用户问“这个图标用什么颜色更合适”时，优先按下面顺序回答：

1. 先判断图标用途：功能图标、强调图标、品牌 logo、图表配套图标
2. 再判断界面风格：极简、企业、科技、活泼、深色、浅色
3. 如果用户给了参考图，先总结图的主观感受：
   - 偏冷还是偏暖
   - 偏轻还是偏重
   - 偏克制还是偏鲜艳
   - 更像工具感、品牌感、内容感还是数据感
4. 给出 `1 到 3` 组颜色建议，不要一次甩太多
5. 明确告诉用户：先把颜色填进 HTML 结果页里试一下视觉感受，再决定是否导出 PNG / ICO

## 基础原则

### 1. 通用功能图标不要太花

适合：

- 单色为主
- 中低饱和度
- 比正文稍强，但不要比主按钮还抢眼

推荐区间：

- 浅色界面：`#334155`、`#475569`、`#0F172A`
- 深色界面：`#CBD5E1`、`#E2E8F0`、`#F8FAFC`

不建议：

- 默认就上高饱和纯红、纯绿、纯蓝
- 每个功能图标都用不同颜色

### 2. 强调图标才用品牌色或强调色

适合：

- 关键按钮
- 核心 CTA
- 重要状态提示
- 首页重点入口

推荐区间：

- 科技蓝：`#2563EB`、`#3B82F6`
- 产品紫：`#7C3AED`、`#8B5CF6`
- 成功绿：`#16A34A`、`#22C55E`
- 警示橙：`#EA580C`、`#F97316`
- 危险红：`#DC2626`、`#EF4444`

### 3. 品牌 logo 优先尊重品牌原色

适合：

- `simple-icons`
- `devicon`
- 用户明确说“要品牌 logo”

建议：

- 第一优先保留品牌原色
- 如果页面太乱，可只保留 logo 主色，其余界面元素收敛为中性色
- 如果用户要“统一风格”，可以先给两版：
  - 品牌原色版
  - 单色统一版

### 4. 图表配套图标不要抢图表本体

适合：

- 数据看板
- 图表角标
- 指标小图标

建议：

- 默认用中性灰蓝、灰青、灰紫
- 只在涨跌、告警、重点指标上使用强调色
- 图标颜色最好比图表主数据线再弱半级

推荐区间：

- 中性数据蓝：`#3B82F6`
- 冷静青色：`#0891B2`
- 企业蓝灰：`#475569`
- 低调紫灰：`#6366F1`

## 按场景给建议

### SaaS / 企业后台 / 控制台

建议：

- 默认图标：`#334155`、`#475569`
- 悬停或当前态：`#2563EB`
- 危险操作：`#DC2626`
- 成功反馈：`#16A34A`

风格判断：

- 要专业、稳定、可长期使用时，优先蓝灰系
- 少用大面积高饱和色

### 科技产品 / AI 工具 / 开发者工具

建议：

- 主色：`#2563EB`、`#4F46E5`
- 辅色：`#06B6D4`、`#7C3AED`
- 中性色：`#334155`、`#64748B`

风格判断：

- 如果参考图偏冷、偏发光、偏数字感，优先蓝紫系
- 如果页面已经有强发光背景，图标本身反而要收一点

### 电商 / 钱包 / 支付 / 订单

建议：

- 默认图标：`#334155`
- 主强调：`#2563EB`
- 支付成功：`#16A34A`
- 优惠活动：`#EA580C`

风格判断：

- 钱包、账单、资产更适合稳重蓝绿，不适合太跳
- 活动促销图标才适合橙红

### 内容社区 / 社交 / 生活方式

建议：

- 默认图标：`#475569`
- 强调色：`#EC4899`、`#F43F5E`、`#8B5CF6`
- 清新风：`#14B8A6`、`#22C55E`

风格判断：

- 如果参考图偏轻松、偏年轻，可以提高一点饱和度
- 但功能图标仍然建议保留统一主色，不要每个都彩色

### 深色界面

建议：

- 默认图标：`#CBD5E1`、`#E2E8F0`
- 强调蓝：`#60A5FA`
- 强调紫：`#A78BFA`
- 成功绿：`#4ADE80`

风格判断：

- 深色界面里不要继续用过深图标色
- 强调色适当提亮，避免发灰

## 有参考图时怎么判断

当用户给了参考图，AI 不需要精确吸色到每个像素，可以按视觉印象做轻量归纳。

### 如果参考图看起来偏冷

特征：

- 蓝、青、紫占主导
- 画面更理性、更科技、更克制

建议：

- 图标优先用蓝灰、青蓝、紫蓝
- 示例：`#2563EB`、`#4F46E5`、`#0891B2`

### 如果参考图看起来偏暖

特征：

- 橙、红、米色、金色较多
- 画面更亲和、更内容化、更有生活感

建议：

- 图标优先用暖灰、橙、珊瑚色
- 示例：`#EA580C`、`#F97316`、`#C2410C`

### 如果参考图看起来很克制

特征：

- 大面积留白
- 中性色占主导
- 颜色数量很少

建议：

- 图标默认用单色
- 强调色只保留一个
- 示例：`#0F172A`、`#334155`、`#2563EB`

### 如果参考图看起来很活泼

特征：

- 颜色更亮
- 对比更强
- 有插画感、营销感

建议：

- 图标可以适度提高饱和度
- 但仍要控制在 `1 个主强调色 + 1 个辅助色`
- 示例：`#8B5CF6`、`#EC4899`、`#22C55E`

## 推荐输出格式

AI 给用户颜色建议时，尽量用这种格式：

```text
建议你先试这 2 组：

1. 稳重企业风
- 默认图标色：#475569
- 当前态 / 强调色：#2563EB
- 危险态：#DC2626

2. 偏科技感
- 默认图标色：#334155
- 强调色：#4F46E5
- 辅助亮色：#06B6D4

你可以先把这几个颜色填到搜索结果页里试一下，再决定导出 PNG/ICO。
```

## 和现有脚本怎么配合

推荐工作流：

1. 先用 `search_icons.ps1` 搜到候选图标
2. 根据用户场景或参考图，给出 `1 到 3` 组颜色建议
3. 让用户先在 HTML 里把颜色调一下感受风格
4. 用户确认后：
   - 要 SVG：用 `get_icon_svg.ps1 -StylePreset`
   - 要 PNG / ICO：用 `export_icon_asset.ps1 -StylePreset`

## 必须避免

- 不要在没有场景判断时直接给一串随机 HEX
- 不要对一批通用功能图标给五颜六色的方案
- 不要把品牌 logo 强行改成与品牌无关的颜色，除非用户明确要求统一风格
- 不要把“参考图的主色”机械照搬到所有图标上，要先判断它适不适合功能图标
