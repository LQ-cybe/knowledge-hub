### 4. 排障攻坚：旭日图"未命名 1486 个 ×2"（跨第 12~13 轮，今日最长单点）

**现象**：正常切换视图无问题，**单击子节点下钻后、点中心圆返回时**出现两个"未命名 1486"扇区。

**三重根因与修复**：
1. **下钻栈引用污染**：旧代码下钻直接 push ECharts 的 `p.data`（渲染数据项），HMR/重载后 hierarchy 引用失效 → 点中心圆判定 `target === 栈尾` 失败 → **重复 push 同一节点**（实测 drillLen 1→2），累积后 ECharts 加工数据丢失 name → 修复：用 **id 回原始树 `findNode(hierarchy, pid)` 取干净节点**入栈
2. **中心圆语义错误**：用户预期"点中心圆=返回上一级"，旧逻辑却当下钻处理 → 修复：中心圆判定改 **`String(target.id) === String(栈尾.id)`**（引用失效兜底），命中即 pop
3. **虚拟根入栈**：初始视图点击中心孔时 ECharts 返回虚拟根（hierarchy 找不到 id），旧兜底 `|| p.data` 把它压栈 → colorize 后 name 兜底成"未命名" → 修复：**去掉 p.data 兜底，找不到干净节点一律不下钻**

**验证**：无头浏览器多轮实测——下钻 2Word → 点中心返回 → 再下钻 → 再返回，drillLen 0/1 循环正确、渲染数据 0 个"未命名"；初始中心孔点击不下钻。

### 5. 其他修复验证

- **弦图**：节点 symbolSize 统一收敛上限 10；连线宽度改固定 1.6（原按共现值变化导致粗细不一，如 3Access↔API声明 那条很细）——实测 option 全部节点 10、全部连线 1.6
- **关系图标签切换"跳动"**：挂 ECharts `finished` 事件实测——开关标签前后 **finished 计数 0 次（force 布局未重启）**，三帧截图（关→开→关）位置一致。结论：第 12 轮 label 上移 series 层 + 局部 patch 已生效、**无位移**；若用户仍见跳动为 vite 热更新残留旧缓存，Ctrl+F5 强刷即恢复
