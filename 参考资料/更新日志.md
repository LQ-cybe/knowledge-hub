## 2026-09-09（第 14 轮迭代：新增书签与笔记两类自建资源——创建/编辑/删除（回收站）全链路）

### —— 自建资源（笔记 / 书签 / 待办）落库与浏览页交互

- **① 后端新增 5 个 API**（`server/src/routes/resources.ts`）：
  - `POST /api/resources`：创建自建资源（type ∈ note/bookmark/todo），校验标题非空、书签链接非空；bookmark 无协议自动补 `https://`（前端处理）；写入 `resources` 表（content 存正文、source_url 存书签链接），FTS 触发器自动同步索引。
  - `GET /api/resources/:id`：资源详情（含 content/source_url/meta），供笔记编辑器加载与书签编辑。
  - `PUT /api/resources/:id`：更新自建资源（标题/内容/链接），仅限 note/bookmark/todo（文件/文件夹走磁盘路径）。
  - `DELETE /api/resources/:id`：**软删进回收站**（status='trashed' + meta.deleted_at），30 天后自动清理（删除时顺带 purge 超期项）；与导图回收站约定一致。
  - `GET /api/resources/trash/info`：回收站统计（count / 自动清理时间 / 30 天），供工作台显示清理信息。
- **② 主目录视图语义修正（关键）**：浏览页默认在主目录（Code）内浏览，原查询 `parent_id=主目录ID` 不含自建资源（笔记/书签 parent_id 为 null，无文件系统归属）→ 新增 **`parentId='root'` 语义**：返回「根文件夹 + 全局所有笔记/书签/待办」。前端在主目录时传 `parentId='root'`，进入子文件夹仍只显示文件。搜索（按文件名）与标签筛选同样作用于自建资源。
- **③ 前端浏览页（BrowserView.vue）**：
  - 工具栏新增「新建 ▾」下拉：📝 新建笔记 / 🔖 添加书签。
  - 新建笔记对话框（标题 + Markdown 内容）→ 创建后**自动打开全屏编辑器**继续撰写。
  - 添加书签对话框（标题 + 链接地址 + 备注）；链接不填协议自动补 https。
  - 列表行点击：笔记 → 打开 Markdown 编辑器（左右分栏，数据库读写）；书签 → 新标签页打开链接。
  - 笔记/书签行**右键菜单**：编辑（笔记开编辑器 / 书签开编辑对话框）、删除（移入回收站，带确认，提示 30 天自动清理）。
  - 表格「路径/链接」列：书签显示完整链接（悬停显示），笔记显示 `-`；卡片 meta 书签显示域名。
- **④ 笔记编辑器（FileEditorView.vue）**：新增 `mode='note'`——加载/保存走 `getResource/updateResource`（数据库 content），与文件型（磁盘读写）并存；复用现有 MD 左右分栏渲染。
- **⑤ 集成确认**：类型筛选下拉已含「笔记/书签」（此前轮次已加）；时间线视图类型筛选已含笔记/书签；工作台统计自动纳入自建资源类型计数；标签功能对自建资源通用（打标后进入标签维度图谱）。
- **⑥ 验证**：后端 API 全链路 curl/node 实测（创建/详情/更新/列表 type 过滤/软删/回收站计数/root 视图 3 项：Code+书签+笔记）；前端 vite build 通过（2702 modules）；浏览器实测新建笔记→自动开编辑器→保存落库、添加书签→列表显示链接、根视图显示笔记/书签、坐标点击笔记行打开编辑器。

### —— 图谱 3 项（旭日图下钻栈重写 / 弦图样式 / 关系图标签开关验证）

- **① 旭日图「未命名 1486 个 ×2」根治（核心）**：复现路径——正常切换视图无问题，**单击子节点下钻后、点中心圆返回时**出现。三重根因与修复：
  - **下钻栈引用污染**：旧代码下钻直接 push `p.data`（ECharts 渲染数据项），HMR/重载后 hierarchy 引用失效 → 点中心圆判定 `target === 栈尾` 失败 → **重复 push 同一节点**（drillLen 1→2），累积后 ECharts 加工数据丢失 name。
  - **中心圆语义**：用户预期"点中心圆=返回上一级"。修复——`chart.on('click')` 用 **id 回原始树 `findNode(hierarchy, pid)` 取干净节点**入栈（name 永不失），中心圆判定改为 **`String(target.id) === String(栈尾.id)`**（引用失效兜底），命中即 pop 返回。
  - **虚拟根入栈**：初始视图点击中心孔时 ECharts 返回虚拟根（hierarchy 找不到 id）→ 旧兜底 `|| p?.data` 把它 push 入栈 → colorize 后 name 兜底为"未命名"。修复——**去掉 p.data 兜底，找不到干净节点一律不下钻**。
  - 实测（无头浏览器多轮）：下钻 2Word → 点中心圆返回 → 再下钻 → 再返回，drillLen 0/1 循环正确、渲染数据 0 个"未命名"。
- **② 弦图样式**：节点 `symbolSize` 统一收敛到 **上限 10**（原用原始值过大）；连线宽度改**固定 1.6**（原按共现值 `Math.min(4, 0.5+v*0.6)` 变化导致粗细不一，如 3Access↔API声明 仅 2 资源共现那条很细）。实测 option：全部节点 10、全部连线 1.6。
- **③ 关系图标签切换「跳动」排查**：挂 ECharts `finished` 事件实测——开关标签前后 **finished 计数 0 次（force 布局未重启）**；三帧截图（关→开→关）节点位置一致。结论：第 12 轮 label 上移 series 层 + 局部 patch 已生效，**无位移**。若用户仍见跳动，多为浏览器旧版本缓存（vite dev 热更新残留），Ctrl+F5 强刷即可。

### —— 图谱 7 项 / 导图 1 项（鱼骨图完全官方：Fishbone.js 重装官方 + 移除 fishboneDeg 72 与 margin 覆盖）

- **① 关系图「显示标签」开关失效根因与修复**：标签原本写在 **data 项**上（`nodes.map(n => ({...label}))`），而 watch(showLabels) 只 patch **series 层** label，两层不重叠 → 切换无效；且 chord 标签在 data 项、pack 是 custom 系列 renderItem 内文字，局部 patch 天然无效。修复：**graph 的 label 上移到 series 层**（formatter/fontSize 12/颜色），开关切换走局部 setOption patch（`lazyUpdate`）→ 不再整图重建、force 布局不再重新收敛（无变动）；chord/pack 仍走重渲染。
- **② 弦图连线减半**：线宽 `Math.min(8, 1+v*1.2)` → **`Math.min(4, 0.5+v*0.6)`**（用户：太粗，一半就够）。
- **③ 旭日图滚轮缩放**：新增 `sunZoom`（1..6）滚轮缩放 radius（`18/sunZoom% → 94/sunZoom%`），levels 环带跟随 radius 等比例缩放。
- **④ 桑基图缩放**：ECharts sankey 官方不支持 roam → 新增 `cssZoom`（1..4）**容器 CSS transform 缩放**（transformOrigin center）。
- **⑤ 真实滚轮被 ECharts 拦截**：canvas 层 wheel 被 zrender/ECharts 拦截，DOM `@wheel` 收不到 → **新增统一 `initChart()`：在 `chart.getZr().on('wheel')` 层监听**（pack 重渲染 / sunburst radius / sankey CSS transform），真实滚轮路径打通；DOM @wheel 保留作兜底。
- **⑥ 放大时节点缩小、标签放大**：关系图节点 symbolSize ×0.7（folder 12.6/file 5.6/tag 15.4）、树图 symbolSize 9→7；**七视图标签字号 11→12**。
- **⑦ 旭日图内层偶现 undefined + 层数重复**：根因——剥离 Code 根后 levels 仍按含根的 maxDepth 生成，多出一层 → 深层节点渲染进空环产生 undefined/错位。修复：**levels 按剥离根后的实际深度 `sunMaxD` 动态生成**；**maxDepth 改为 `hierarchyDepth(hierarchy)-1`**（Code 根不算可见层，DB 实测最深可见 4 层 → 下拉仅 1..4，「第 5 层」冗余消除）；colorize 增加 name 兜底（缺 name 回退 data.title，杜绝 undefined）。
- **⑧ 鱼骨图「恢复到最开始的版本，完全不改」**：node_modules Fishbone.js 第 6~8 轮中文紧凑补丁残留 → **删除包目录强制重装官方 `simple-mind-map@0.14.0-fix.3`**（dist 核实无补丁）；MindmapView 移除 `fishboneDeg: 72`（回官方 45°）与 radial 分支 `second.marginX/marginY`、`node.marginY` 覆盖（**鱼骨图不再做任何间距/角度定制**；其他布局保留第 8 轮纵向 marginY 9/12 修复）；「放射布局测试」（30 节点）实测官方鱼骨布局正常、无重叠无孤立节点。
